# 1518 网站制作项目

这个项目用于制作部署到 `1518.com` 下的起名/测算类网站。

## 当前目标

- 参考方向：传统起名/测算工具站的公开信息架构
- 目标域名：`1518.com`
- 交付方向：独立网站项目，可本地预览，后续可部署
- 当前阶段：项目拆分与需求迁移

## 已确认的功能范围

- 首页信息架构
- 宝宝起名
- 公司起名
- 品牌起名
- 姓名测试
- 周公解梦
- 公司名测试
- 品牌名测试
- 生肖查询
- 生肖配对
- 星座查询
- 星座配对
- 生日解析
- 风水查询
- 血型分析
- 血型配对
- 五运六气
- 手机号测算
- 车牌测算
- 文章列表与文章详情
- 订单查询入口

## 版权与实现边界

如果拥有原站内容、素材、代码或数据库授权，可以按授权材料做完整迁移。

如果没有源代码和授权素材，本项目将使用原创代码、原创页面结构实现同等功能流程，不直接复制对方受版权保护的代码、图片和长篇文案。

## 本地运行

第一版会优先做成静态前端项目，后续根据需要升级为带后端/API/数据库的版本。
