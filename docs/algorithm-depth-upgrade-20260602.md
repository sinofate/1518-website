# 1518 算法深度升级记录

日期：2026-06-02

## 本次升级范围

- 姓名测试：继续使用 `lunar.js` 四柱八字、五格数理、三才配置、用字五行和综合评分。
- 个人起名：候选名不再使用简单文本分，改为逐个候选名调用姓名测试引擎，按八字喜用、五格、三才、用字补益和生僻/重复风险排序。
- 公司名测试：综合评分加入商号长度、行业字根、禁限词风险和行业元素匹配，不只看全称总格与商号格。
- 公司起名：候选名按全称数理、商号数理、行业元素、关键词适配、传播长度和禁限词风险综合排序。
- 品牌起名：候选名按数理、品牌气质、品类联想、名称长度、读写记忆度和通用词风险综合排序。
- 品牌名测试：报告增加综合评分、音节长度、品类联想、传播风险和商标核验提醒。

## 2026-06-02 准确性 90 分升级

- 姓名测试不再用默认日期伪造八字：缺少出生日期或出生时辰时，八字项自动降为保守参考，并显示测算置信度。
- 姓名评分加入用字质量层：估算笔画、生僻高笔画、重复字、负面字义、生肖偏旁冲突都会明确扣分并在报告中说明。
- 音韵模块移除伪造声母韵母：当前只输出可复核的声调节奏和重复风险，等待拼音/多音字库接入后再输出精确声母韵母。
- 生肖六合六冲改为按实际生肖动态输出，不再写死马年关系。
- 公司名测试新增商号自动抽取：未填写商号简称时，会从公司全称中剔除地域、行业词和组织形式后再计算商号格。
- 公司名评分权重调整为全称数理、商号数理、行业适配、行业字根、传播长度、扩张稳定与合规风险扣分共同决定。
- 公司起名和品牌起名同步加强显著性、组织形式、限制词、通用宣传词、长度和读写风险扣分。
- 手机号和车牌测算降低随机文本分占比，加入数字均衡、输入完整度、重复号、顺逆连号等可解释结构指标。
