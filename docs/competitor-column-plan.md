# 1518 全栏目竞品拆解与栏目架构

更新时间：2026-06-02

## 目标边界

1518 的首页第一印象要保留老用户熟悉的红色导航、双栏结构、工具入口密度和“测算/起名/查询”路径；内页不复制竞品文案、代码和素材，而是以原创报告页、明确算法说明和可继续接数据库的结构重建。

所有玄学、民俗、星座、血型、梦境类内容统一标注为传统文化、民俗娱乐与自我观察参考，不作为医学、法律、金融、婚恋决策依据。

## 竞品总览

### 起名、测名、公司品牌命名

参考站：

- 1518：公开页面仍覆盖姓名测试、宝宝起名、公司名称测试、品牌名称测试、周公解梦、五运六气、车牌和手机号码等入口；移动页声明“相关内容来自传统文化及东西方民俗文化，仅供娱乐参考”。资料来源：https://m.1518.com/
- 美名腾：宝宝起名、姓名测试打分、公司起名、专家起名、英文名、小名等，突出“全方位信息、文化内涵和时尚元素”。资料来源：https://www.meimingteng.com/ 与 https://www.meimingteng.com/Naming/
- 起名类新站：起名网/名易得/快起名等普遍强调八字起名、周易取名、AI 智能取名、名字测评、姓名对比、诗词和常用字库。资料来源：https://qmz.in/ 、https://www.mingyide.cn/ 、https://www.kuaiqiming.com/

功能拆解：

- 输入侧：姓氏、单复姓、性别、公历/农历、出生年月日时分、字数偏好、行业、主体字号。
- 计算侧：八字喜用、五格剖象、三才五行、康熙笔画、易经数理、音形义、生肖偏旁、诗词典故、行业属性。
- 输出侧：综合评分、分项评分、候选名列表、逐字解释、避坑提示、付费深度报告或专家服务。

1518 方案：

- 宝宝起名：保留首页表单，升级为报告页候选名列表，显示八字补益、五格、音义、生肖与诗词维度。
- 公司起名：从公司测试引擎延伸，输入行业、地域、主体偏好，输出候选商号、全称模板、数理和行业适配。
- 品牌起名：面向产品、店铺、商标，增加记忆度、传播音节、商标风险提示。
- 品牌名测试：复用公司名测试结构，但重点看传播力、品类联想、受众匹配、音节和负面谐音。

## 产品栏目架构

### 页面层

- 首页：保留老 1518 的导航密度、红色品牌感、首页起名表单、热门服务和右栏快速入口。
- 栏目页：当前阶段采用单页多锚点，所有栏目都有独立表单和报告结果；后续可拆成真实 URL。
- 报告页：统一使用姓名测试/公司名测试的 A4 纸张式 `.report-pdf-page` 风格。

### 数据与算法层

- `NameSharedData`：易经数理、等级、常用康熙笔画，姓名和公司共享。
- `NameEngine`：姓名五格、三才、八字、喜用神。
- `columns-tools.js`：其他栏目的表单配置、轻量算法、报告生成器。
- 后续数据库：全量康熙笔画、拼音多音字、诗词库、梦境词库、生肖偏旁、星座文案库、风水规则库、五运六气年表。

### 内容权威性原则

- 可计算的内容使用明确公式：日期星座、生肖年、六合三合、易经数理、五格公式。
- 民俗内容标注来源性质：传统梦书、民俗经验、现代心理解释分开写。
- 不输出绝对结论：用“参考、倾向、建议、宜关注”替代断言。
- 对健康、财务、婚恋等高影响问题明确提示不构成专业建议。
