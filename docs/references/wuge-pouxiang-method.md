# 五格剖象法本地规则说明

整理日期：2026-06-02

本项目采用五格剖象法作为姓名测试的传统文化参考算法之一。五格剖象法通常以康熙字典笔画为基础，把姓名拆成天格、人格、地格、外格、总格，并结合易经数理、三才五行、阴阳配置等进行解释。

## 五格计算

### 单姓单名

- 天格 = 姓笔画 + 1
- 人格 = 姓笔画 + 名笔画
- 地格 = 名笔画 + 1
- 外格 = 2
- 总格 = 姓笔画 + 名笔画

### 单姓双名或多名

- 天格 = 姓笔画 + 1
- 人格 = 姓笔画 + 名第一字笔画
- 地格 = 名各字笔画相加
- 外格 = 名最后一字笔画 + 1
- 总格 = 全名笔画相加

### 复姓单名

- 天格 = 复姓两字笔画相加
- 人格 = 复姓第二字笔画 + 名笔画
- 地格 = 名笔画 + 1
- 外格 = 复姓第一字笔画 + 1
- 总格 = 全名笔画相加

### 复姓双名或多名

- 天格 = 复姓两字笔画相加
- 人格 = 复姓第二字笔画 + 名第一字笔画
- 地格 = 名各字笔画相加
- 外格 = 复姓第一字笔画 + 名最后一字笔画
- 总格 = 全名笔画相加

## 五格含义

- 天格：姓氏格，偏祖辈、先天环境、家族背景。
- 人格：主格，偏性格核心、中年运势、主要人格能量。
- 地格：前运，偏青年阶段、基础环境、家庭与下属缘。
- 外格：外缘，偏社交、人际、外部合作与公众印象。
- 总格：后运，偏整体走势、长期发展和晚年趋势。

## 三才配置

三才取天格、人格、地格的五行关系。五行按数理尾数映射：

- 1、2：木
- 3、4：火
- 5、6：土
- 7、8：金
- 9、0：水

相生：木生火，火生土，土生金，金生水，水生木。
相克：木克土，土克水，水克火，火克金，金克木。

## 资料说明

五格剖象法属于传统姓名学/民俗文化算法，存在不同流派差异。本项目把它作为娱乐参考和报告生成规则，不构成专业建议。
